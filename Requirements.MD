# Requirements

Potential requirements for compiling SONIC THE HEDGEHOG 4: Episode 1.

Linux compiling may be similar or easier to the compilation steps for Windows, however that is currently untested.



# Absolute Requirements

Requirements that are known to be required for compilation.



## XCode/Apple Systems

### iOS

* An appropriate version of XCode if compiling for iOS/iPadOS, as the original code was bundled in an XCode project. May not work on current versions of any of what's listed however.

### macOS X/macOS

* Due to XCode potentially being compatible, there could be the possibility of compiling for macOS. No guarantees.



## Windows

For this project, I used Kea Sigma Delta's CMake Tutorial for beginners to compile this, so many requirements there may work here.

* Visual Studio Code (Tested with VSCodium, which is a derivative of it.)
* Cmake - (to compile C++ code.)
* Microsoft Visual Studio 2019 x85



## Other Systems

Code exists for versions such as the Wii, PlayStation 3, and XBOX 360 versions of the game, however there is a probability that these systems may require official SDKs, in which we aren't including. 



# Potential Requirements

Requirements that may not be required to compile, but are recommended.

These will be removed when it can be confirmed that these are not required.

## Windows

* Microsoft Visual Studio. (Version 2019 was used.)
* Windows 8.1 or higher.
